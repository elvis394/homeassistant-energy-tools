# Energy Day Balance

Berechnet Tagesverbrauch, Solarertrag, Netzeinspeisung, Autarkiegrad und Selbstverbrauchsquote aus kumulativen kWh-Entities in Home Assistant.

Die Weboberfläche läuft per Ingress direkt in Home Assistant. Dort können mehrere Solarquellen sowie je eine Entity für Netzbezug und Netzeinspeisung ausgewählt werden.
